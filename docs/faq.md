# 常见问题

## 安装与打开

**macOS 提示「无法验证开发者」/「已损坏，无法打开」。**
安装包没有开发者签名与公证。「系统设置 → 隐私与安全性」里点「仍要打开」，或在终端执行 `xattr -dr com.apple.quarantine /Applications/iLife.app`。步骤见[安装说明](install.md#macos安装与首次打开)。

**Windows SmartScreen 拦截 / 杀毒软件报警。**
点「更多信息 → 仍要运行」；杀毒软件拦截时把 iLife 安装目录加入信任。请只从本仓库的 Releases 下载。

**macOS 12 能装吗？**
不能，最低 macOS 13（Ventura）。

**怎么升级？**
没有自动更新。下载新版本覆盖安装（macOS 拖入「应用程序」选「替换」，Windows 直接运行新安装包），数据目录保留。macOS 上开启过电脑操作的，升级后要重新授权屏幕录制 / 辅助功能。

**从 0.2.0 升级后旧对话不见了。**
0.3.0 更换了智能体底座，0.2.0 的对话记录不会迁移。模型服务等设置请检查一遍。

## 模型

**「测试连接」失败 / 对话里出现 `Connection error`。**
模型请求由你的电脑直接发给你填的地址，不经过 iLife 的服务器。先在浏览器或终端确认这个地址在当前网络能访问：只在公司内网可用的地址，在家里连不上。
再检查 API 地址是否以 `/v1` 这类前缀结尾（末尾多写的 `/chat/completions` 会自动去掉）、模型 id 是否正确、Key 是否有效。

**哪些模型能用？**
任意 OpenAI 兼容（`/chat/completions`，流式 + 工具调用）的服务。模型需要支持工具调用，否则只能聊天；要用电脑操作，模型还需要支持图片输入并打开「支持图片」。

**API Key 存在哪里？**
本机数据目录的配置文件里：Windows 用系统密钥（DPAPI）加密；macOS 以仅本人可读的文件权限保存，不用钥匙串。Key 不会写进智能体的配置文件，智能体运行的命令也看不到它。

## 智能体

**它改了工作目录之外的文件 / 执行了危险命令？**
默认档位「工作区可写」只允许写工作目录与临时目录；命令在 macOS 的系统沙箱里运行，**Windows 上没有沙箱**，与你自己在终端里运行的权限相同。
不放心的任务用「只读」档位（「设置 → 通用」）；「完全访问」档位则完全不受限制，只在信任任务内容时使用。电脑操作与内置浏览器不在沙箱里，相当于你本人在操作。

**电脑操作开了没反应（macOS）。**
检查「设置 → 能力」里屏幕录制与辅助功能的授权状态；授权屏幕录制后需要重启 iLife。升级版本后 macOS 会把它当成新应用，要在系统设置里删掉旧的 iLife 条目重新授权，或用 `tccutil reset`（见[安装说明](install.md#电脑操作需要的系统权限)）。

**关掉电脑操作开关后系统权限还在？**
是的，关闭开关不会撤销系统授权。不再需要时在「系统设置 → 隐私与安全性」里关掉 iLife 的屏幕录制与辅助功能。

**Windows 上操作不了某个窗口。**
普通权限运行的 iLife 无法操作「以管理员身份运行」的程序窗口，这是系统限制。

**智能体操作网页时我能插手吗？**
可以。侧边栏的浏览器就是它用的浏览器，随时可以自己点、自己输入；登录过的网站其它对话也能用。

## 团队与插件

**团队下发的 MCP 服务显示「需要 HTTPS」。**
接入地址是明文（不是 `https://`，也不是本机）时，插件包可能被同一网络里的人替换，iLife 只启用技能、停用 MCP 服务与提示词（「设置 → 团队插件」里标为「需要 HTTPS」）。确实可信的内网可以在「设置 → 团队」打开「允许明文服务端下发可执行插件」。

**关闭团队连接后插件都不能用了。**
团队下发的插件只在连接开启时生效，重新开启后恢复。自己添加的技能与 MCP 不受影响。

**「接入地址无效或团队不存在」。**
接入地址要整段照填（有域名是 `https://<团队>.<域名>`，没有域名是 `http://<ip>:8787/t/<团队>`），不要自己去掉 `/t/<团队>`；团队已停用时会提示「团队已停用」，联系管理员。

## 数据与日志

| 内容 | macOS | Windows |
|---|---|---|
| 数据目录（配置、会话、插件、日志） | `~/Library/Application Support/iLife` | `%APPDATA%\iLife` |
| 日志 | `<数据目录>/logs/main.log` | 同左 |
| 默认工作目录 | `~/Documents/iLife` | `文档\iLife` |

反馈问题时请附上 iLife 版本、系统版本、复现步骤，以及日志里相关的几行（删掉 API Key、网址等不想公开的内容），到 [Issues](https://github.com/ch-liuzhide/ilife-releases/issues) 提交。
